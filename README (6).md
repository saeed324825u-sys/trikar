# نماز و عادات ٹریکر — Prayer & Daily Habit Tracker

ایک مکمل آف لائن، ذاتی اور محفوظ Progressive Web App — بغیر کسی سرور یا بیک اینڈ کے۔

---

## یہ ایپ کیا کرتی ہے؟

### 🕌 12 ماہی نماز ٹریکر
- پورا سال — جنوری سے دسمبر، ہر مہینہ 30 دن
- ہر دن کی پانچوں نمازیں (فجر، ظہر، عصر، مغرب، عشاء) الگ الگ ٹریک کریں
- ہر نماز چار حالتوں میں سے ایک پر ہوتی ہے — ایک کلک سے اگلی حالت پر جائیں:
  - ⬜ **خالی** — ابھی کچھ درج نہیں
  - 🟢 **ادا** — وقت پر پڑھی
  - 🟡 **قضا** — وقت کے بعد پڑھی
  - 🔴 **ترک** — نہیں پڑھی
- ہر دن کے سامنے رنگین سگنل بیڈ — ایک نظر میں پورے دن کا حال
- "سب ادا" اور "ری سیٹ" کے فوری بٹن
- ماہانہ اعداد و شمار: کل ادا، قضا، ترک، خالی

### ✅ یومیہ عادات ٹریکر
- پانچ روزمرہ عادات: کھانا، مطالعہ، ورزش، تفریح، 8 گھنٹے نیند
- ہر دن کے لیے پروگریس بار
- 12 مہینوں کا مکمل ریکارڈ

### 🔔 یاد دہانیاں
- ہر نماز کے لیے الگ وقت مقرر کریں
- ہفتہ وار جائزے کی یاد دہانی
- ایپ کھلی ہو تو عین وقت پر اطلاع
- انسٹال شدہ حالت میں Chrome/Android پر پس منظر میں بھی کوشش

### 📊 ڈیٹا اور تجزیات
- سال بھر کی مجموعی کارکردگی
- ماہانہ بار چارٹ اور رنگ چارٹ
- موجودہ اور بہترین لگاتار ادا دنوں کا ریکارڈ

### 🔐 سیکیورٹی اور بیک اپ
- ایک سے زیادہ پروفائل — ہر ایک الگ PIN یا پاس ورڈ سے محفوظ
- ڈیٹا **AES-256-GCM** سے اِن‌کرپٹ — صرف آپ کے PIN سے کھلتا ہے
- JSON بیک اپ: کسی بھی وقت ڈاؤن لوڈ کریں، کہیں بھی بحال کریں
- کوئی سرور نہیں، کوئی اکاؤنٹ نہیں، کوئی ٹریکنگ نہیں — سب کچھ آپ کے ڈیوائس پر

## فائلیں

```
index.html      ← پوری ایپ (HTML + CSS + JS ایک فائل میں)
manifest.json   ← PWA انسٹالیشن کے لیے
sw.js           ← آف لائن سپورٹ اور پس منظر یاد دہانیوں کے لیے
```

> ⚠️ تینوں فائلیں ایک ہی فولڈر میں رکھنا ضروری ہے۔

---

## چلانے کا طریقہ

### VS Code (مقامی ٹیسٹنگ)
1. VS Code میں فولڈر کھولیں
2. **Live Server** ایکسٹینشن انسٹال کریں
3. `index.html` کھول کر نیچے **"Go Live"** دبائیں

### GitHub Pages (مستقل لنک، فون پر انسٹال کے لیے)
1. GitHub پر نئی Public repository بنائیں
2. تینوں فائلیں اپ لوڈ کریں
3. Settings → Pages → Branch: main → Save
4. `https://username.github.io/repo-name` پر ایپ چلنے لگے گی

### فون پر انسٹال
- **Android / Chrome:** مینو → "Install app"
- **iPhone / Safari:** Share → "Add to Home Screen"

## ایک ضروری بات

PIN یا پاس ورڈ بھول جانے پر ڈیٹا واپس **نہیں** آ سکتا — یہ کمزوری نہیں، اصل اِن‌کرپشن کی یہی قیمت ہے۔ اس لیے:
- بیک اپ باقاعدگی سے لیتے رہیں (ڈیٹا ٹیب سے)
- PIN یاد رکھیں یا کہیں محفوظ لکھ کر رکھیں

## Tech Stack

| چیز | تفصیل |
|-----|--------|
| Frontend | Vanilla HTML / CSS / JavaScript — کوئی فریم ورک نہیں |
| Storage | IndexedDB (بڑی صلاحیت، آف لائن) |
| Encryption | Web Crypto API — PBKDF2 + AES-256-GCM |
| Offline | Service Worker + Cache API |
| Fonts | Google Fonts — Noto Nastaliq Urdu + Vazirmatn |
| PWA | Web App Manifest + Periodic Background Sync |
